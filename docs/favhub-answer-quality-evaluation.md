# FavHub 回答质量人工评测

这是可重复执行的人工评测流程。题目来自
`tests/fixtures/favhub-answer-quality-questions.json`。评测记录不得提交真实的个人收藏、正文、链接或其他用户数据。

## 每题记录

记录问题和实际查询、检索到的条目 ID、最终回答、全部重要主张数、已覆盖的重要主张数、每题覆盖率、六项分数、硬失败标记和评审备注。评分为 0–4 分；1 和 3 分表示介于相邻标准之间。

## 重要主张与引用覆盖

重要主张是会改变用户结论或行动的事实、推荐、比较或步骤主张；过渡语和明确为暂时构思的头脑风暴不算。已覆盖的标准如下：

- 来自 FavHub 的主张紧邻 `citation_id`。
- 当前外部主张有具名来源和 URL。
- Agent 推断同时明确标为 Agent 推断、推荐或假设，且其支持的收藏或外部事实已有引用；只有标签不算覆盖。

每题覆盖率 = 已覆盖的重要主张数 / 全部重要主张数。若回答诚实说明证据不足、没有提出未支持的主张，且重要主张数为 0，则按 100% 记录（0/0 的特例）。引用覆盖率的分数：0 分为 0%，1 分为 1–49%，2 分为 50–89%，3 分为 90–99%，4 分为 100%。

| 维度 | 0 分 | 2 分 | 4 分 |
| --- | --- | --- | --- |
| 相关性 | 未回答问题或偏题 | 回答部分问题 | 直接完整地回答问题 |
| 忠实性（相对检索结果和全文证据） | 结论与证据冲突或无依据 | 主要结论有依据，但有明显遗漏或模糊推断 | 每个结论都能由已读证据支持，并说明不确定处 |
| 完整性 | 遗漏关键部分 | 覆盖主要部分，但缺少重要角度 | 覆盖问题要求的关键部分和必要限制 |
| 可执行性 | 对该题型不可用 | 有部分可用信息，但缺少重要核验、标准或下一步 | 见下方按题型的 4 分标准 |
| 引用覆盖率 | 0% | 50–89% | 100% |
| 新鲜度与来源标注 | 未标注来源，或把旧内容当作当前事实 | 有部分来源、时间或时效提醒 | 清楚标明来自个人收藏、外部资料或推断，并提示时间范围与局限 |

可执行性按题型评分：对 find / summarize，回答可用于定位、理解或继续核验；4 分要求给出具体来源、清晰组织或核验方法，直接且完整的回答无需另列行动计划。对 recommend / compare / plan，4 分要求有可行的下一步或清楚的决策标准；只有泛泛建议为 2 分，不能支持选择或行动为 0 分。

没有时效性主张的题目不应被扣分：来源标注完整，并正确说明无需做新鲜度检查，可在新鲜度与来源标注得 4 分。

## 硬失败与评审边界

无论数值评分如何，以下任一情况都是硬失败：

- 具体事实被表述为有来源的事实或用作证据，但在已读 FavHub 证据和已核验的外部来源中不存在，或被错误归属，或与证据矛盾却未披露。
- 标题级条目不能作为详细步骤的证明；若据此宣称详细步骤，属于硬失败。

明确标为 Agent 推断、推荐或假设，且支持事实已引用的内容，不会自动构成硬失败，应按六项分数正常评估。未引用但独立真实或常识性的表述会降低引用覆盖、来源标注和忠实性；只有它是错误的、错误归属的，或被当作捏造证据使用时，才算硬失败。评审应按此边界决定硬失败，而不是把所有推断一律判错。

## 通过标准

- 硬失败为零。
- 六个维度分别跨 20 道题计算算术平均。某维度平均分 = 20 道题该维度得分之和 / 20；六个维度各自都必须不低于 3.0。不能用每题六项分数的平均值替代，也不能用全部 120 个分数的总平均替代。
- 全部 20 题的微平均引用覆盖率不低于 90%：总已覆盖重要主张数 / 总重要主张数 >= 90%，不是每题百分比的平均值。

评审应使用实际检索出的条目和已读取的全文核对回答；这是人工评测协议，不是自动判定，也不应把任何个人内容或评测记录提交到仓库。
